# AI-Based Radar Target Classification

## Overview
This project aims to classify radar targets using FMCW radar data and Deep Learning.

## Features
- Radar data loading
- Data preprocessing
- Range-Doppler map visualization
- CNN-based target classification
- FastAPI backend
- React frontend

## Tech Stack
- Python
- TensorFlow
- OpenCV
- NumPy
- FastAPI
- React
